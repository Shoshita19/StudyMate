StudyMate – Student Task & Study Planner

StudyMate is a web-based application designed to help students organize their academic activities and manage their time effectively. It provides a simple and user-friendly platform to track tasks, plan study sessions, monitor progress, and stay organized.

Features

- Dashboard with daily task and study progress overview
- Add, edit, delete, and track tasks
- Task priorities and subject-wise categorization
- Search, filter, and sort tasks
- Study timetable and calendar view
- Exam and assignment tracking
- Subject-wise notes management
- Study timer and daily study goals
- Student profile and theme settings
- Export tasks to CSV
- SQLite database for storing information
- Responsive user interface

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: SQLite

Objective

The main objective of StudyMate is to make academic planning easier by bringing task management, study scheduling, and progress tracking together in one application.
